# Objetivo do Projeto
Este projeto tem como objetivo analisar a exportação do petróleo, abordando seus principais aspectos econômicos e estratégicos.
Serão apresentadas informações relevantes sobre o funcionamento desse mercado no cenário global.
O trabalho também trará curiosidades que ajudam a compreender melhor a importância do petróleo.
Assim, busca-se ampliar o conhecimento sobre esse recurso essencial para a economia mundial.


## Tecnologias Utilizadas

* Jira Software
* Power BI
* Microsoft Excel
